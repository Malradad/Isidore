# Live streams (collected by Audrey)

Per stream: `<date> <id>.meta.json` (incl. live start time, New York), `<date> <id>.txt` (transcript),
`<date> <id>.trades.md` (every TAKE / EXIT / SKIP he makes on stream), `frames/<id>/<time>/` (only
around trade moments). `INDEX.md` lists all streams and their status.
