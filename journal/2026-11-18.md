**Quirks / lessons**
- Shift+B / Shift+S fire an **instant market order** with One-click trading on. There's no ticket and no confirmation, and the order goes out **naked, with no stop**. This is the biggest risk found: a stray keypress opens an unprotected position.
- The ~20–33 s edit times are mostly my own tool round-trips (screenshot → click → type → confirm), not TradingView lag. A human using the chart drag handles would be faster. Either way, the position sat **unprotected for 20–30 s** after each hotkey fill.
- To edit a stop or target: Positions tab → pencil → toggles + price fields → Confirm. The dialog shows the tick distance (160 ticks = 40 pts).
- Safer alternative to the hotkeys: use the order ticket with TP/SL toggles on (Test 1). It attaches the bracket in the same click, though offsets are measured from the quote, not the fill.

**Unplanned trade (my error).** Before staging, I clicked the chart's floating BUY button to "open the ticket". With One-click trading on, that button is an **instant market order**: Buy 1 at 27,344.50, ~03:29:03, **no stop**. I flattened it at once (Sell 27,352.00, ~03:29:14), so it was **naked ~12 s**, +7.50 pts = +$15.00. Lesson: the chart's floating SELL/BUY buttons behave like Shift+S/Shift+B. To open the ticket, use the **Trade** button at the top right.

Account after: **$50,048.50**, realized +$48.50 for the day (Tests 1–3). Positions: empty. Orders → Working: empty. Brackets show as Cancelled.

**Comparison with Test 2 (hotkeys).** Hotkey fills were just as fast (≤1–2 s), but the position stayed naked for 20–33 s while the stop was added. The pre-staged ticket fills in **~0.8 s with the bracket already attached**, so it is never unprotected. **Execution rule: use the pre-staged ticket for entries. Never use the hotkeys or the chart's floating buttons.**

**Quirks**
- After each submit, the ticket resets to "Start creating order" and both TP/SL toggles turn **off**. You must re-stage (side + toggles) before every entry. Tick values are kept.
- Bracket offsets are again measured from the quote at submit time and then adjusted ("Take Profit order modified" toast). The result was off-center from the fill by up to ±1.25 pts (±$2.50).
- Clicking a fill toast switched the chart symbol to MNQZ2026. I set it back to MNQ1!.
